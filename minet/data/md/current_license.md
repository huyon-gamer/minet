# minet のライセンスのお話

## ライセンスってなに？

プログラムには、作った人がいます。ライセンスは、
「このプログラムを使っていいよ。ただし、この約束は守ってね」
と書いたルールの紙です。

minet は、自分で作った部分だけでは動きません。NuGet という場所から、
ほかの人たちが作った便利なプログラム部品も借りています。
借りた部品を入れたまま minet を配るときは、その部品を作った人の名前と
ルールも、一緒に見られるようにする必要があります。

## 今回したこと

### 1. minet 自身のルールを入れた

リポジトリの `LICENSE` は、minet 自身のルールです。minet は MIT License
という、使ったり直したり配ったりしやすいルールで公開しています。

### 2. 借りた部品のルールを集めた

`THIRD-PARTY-NOTICES.md` には、NuGet から借りている部品について、次のことを
書いています。

- 部品の名前と番号
- どんなライセンスか
- 作った人の名前
- ライセンスの文章や、必要な「ありがとう」の文章

このファイルは、`scripts/Generate-ThirdPartyNotices.ps1` が自動で作ります。
そのため、部品を新しくしたときに、古い説明をうっかり残しにくくなります。

### 3. 配る ZIP にライセンスを入れるようにした

Windows 用の minet を配るときは、次の 2 つが ZIP の中に入ります。

- `LICENSE`: minet 自身のルール
- `THIRD-PARTY-NOTICES.md`: 借りた部品のルール

ダウンロードした人も、あとからルールを確認できます。

### 4. 部品のリストを固定した

`minet/packages.lock.json` は、「今回使う部品はこれ」と決めたリストです。
同じ minet を作るときに、知らないうちに別の部品へ変わらないようにします。

### 5. 部品表も作った

`sbom/minet.cdx.json` は SBOM（エスボム）です。これは、お店の材料表のような
ファイルです。minet にどの部品が入っているかを、ほかのコンピューターでも
読みやすい形で書いています。

### 6. GitHub で見張るようにした

GitHub Actions は、変更を送ったときに自動で確認する係です。

- 部品のリストどおりに作れるか
- ライセンスの説明と SBOM を作り直しても同じか
- `v` で始まるタグを付けたとき、Windows 用 ZIP と SBOM を Release に置けるか

を確認します。

## 少し特別な部品

`diskann-garnet` 4.0.0 は、部品の箱の中にライセンスの説明が入っていませんでした。
そこで、作った人の公式ページにあるライセンスと「ありがとう」の文章を人が確認し、
`scripts/LicenseOverrides.json` に理由と確認日を書きました。

この部品の番号を変えるときは、前の確認をそのまま使わず、もう一度確認します。

## やりすぎになっていない？

結論から言うと、GitHub で Windows 用の実行ファイルを配るなら、今回の対応は
**やりすぎではありません**。ライセンスを一緒に配ること、部品の番号を固定すること、
部品表を付けることは、間違いを見つけやすくするためのまじめな準備です。

ただし、少し丁寧すぎるところはあります。

- `THIRD-PARTY-NOTICES.md` は約 88 KB あります。MIT License の同じ文章を、たくさんの
	部品ごとに書いているからです。これは間違いではありませんが、将来は「MIT の文章は
	1 回だけ書き、部品の名前を一覧にする」形に小さくできます。
- SBOM は GitHub Release に付けるだけでも役に立ちます。小さな個人用プログラムなら、
	すぐに使う人のためには必須ではありません。それでも、何が入っているかを後から
	調べられるので、公開して配る minet にはちょうどよい対応です。
- GitHub Actions は変更のたびに少し時間を使います。今は部品の変更漏れを防ぐ効果の方が
	大きいです。開発がとても頻繁になって重く感じたら、SBOM の作成だけを Release 時に
	限ることを検討できます。

いちばん大切なのは、部品を更新したときに次を実行して、変わったところを読むことです。

```powershell
dotnet restore minet/minet.csproj
./scripts/Generate-ThirdPartyNotices.ps1
./scripts/Generate-Sbom.ps1
git diff -- minet/packages.lock.json THIRD-PARTY-NOTICES.md sbom/minet.cdx.json
```

これは法律の最終判断をする紙ではありません。心配な配り方や会社での利用をするときは、
くわしい人にも相談します。
